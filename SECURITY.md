# Security Policy

## Supported versions

Plume is pre-1.0. Security fixes are issued only against the latest release
published on [Hex](https://hex.pm/packages/plume).

## Reporting a vulnerability

Please report suspected vulnerabilities privately via GitHub's
[private vulnerability reporting](https://github.com/scott-ray-wilson/plume/security/advisories/new).
Do not open a public issue or pull request for security concerns.

You can expect an acknowledgement within 7 days. Once a fix is released, the
advisory will be published with credit to the reporter unless anonymity is
requested.
